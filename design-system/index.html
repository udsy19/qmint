Evidence labels

Glyph shape = origin; glyph colour = tone. Only CERTIFIED is mint.

evidence kind
  • CERTIFIED-NUMERIC: Numeric bound with rigorous residual accountingNumeric bound with rigorous residual accounting
  • DIGITIZED-FIGURE: Read off a published figure; carries digitization errorRead off a published figure; carries digitization error
  • MEASURED-LATENCY: Latency from real measurementsLatency from real measurements
  • MODELLED-LATENCY: Latency from a model (light-cone, queue model); not a measurementLatency from a model (light-cone, queue model); not a measurement
  • MONTE-CARLO (lower bound): Sampled attack success: a LOWER bound on worst-case attack success, never an upper boundSampled attack success: a LOWER bound on worst-case attack success, never an upper bound
  • NUMERICAL: Floating-point SDP solver output; not a proof without residual accountingFloating-point SDP solver output; not a proof without residual accounting
  • PHOTON-EXPERIMENT: Real recorded photon events with dataset hashReal recorded photon events with dataset hash
  • PUBLISHED-AGGREGATE: Number quoted from a paper table or textNumber quoted from a paper table or text
  • THEOREM: Bound transcribed from a peer-reviewed proofBound transcribed from a peer-reviewed proof
  • QPU: Actual quantum hardware job with job idActual quantum hardware job with job id
  • SIMULATOR-IDEAL: Noiseless circuit/statevector simulationNoiseless circuit/statevector simulation
  • SIMULATOR-NOISY: Simulation under a declared noise modelSimulation under a declared noise model
  • SYNTHETIC: Generated fixture or hypothetical scenarioGenerated fixture or hypothetical scenario
  • UNCERTIFIED: No applicable evidenceNo applicable evidence
certificate status
  • CERTIFIED: Every target met by an applicable, independently checked boundEvery target met by an applicable, independently checked bound
  • INFEASIBLE: Applicable bounds exist but targets cannot be metApplicable bounds exist but targets cannot be met
  • OUT-OF-MODEL: Request violates the proof's trust/physical modelRequest violates the proof's trust/physical model
  • UNCERTIFIED: Missing bound, assumption or independent checkMissing bound, assumption or independent check
  • UNSAFE: An attack exceeds the claimed bound or targetsAn attack exceeds the claimed bound or targets
api status
  • DEMO ADAPTER: Demonstration computed from analytic / published formulas or merged lane-F/G code while the owning lane is not merged; not that lane's outputDemonstration computed from analytic / published formulas or merged lane-F/G code while the owning lane is not merged; not that lane's output
  • NOT AVAILABLE: Nothing honest to show yet; see the reasonNothing honest to show yet; see the reason
