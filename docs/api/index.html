API reference

Every endpoint of the FastAPI research API, generated from openapi.json.

Conventions

QMint Research API 1.0.0. Evidence-labelled research API over merged QMint lanes. Research platform only: not money, not a payment service. Base path /api/v1; JSON only; the web app calls it same-origin through a Next.js rewrite.

  • Every response is an envelope: status (OK, DEMO_ADAPTER or NOT_AVAILABLE), evidence_kind of the headline numbers, provenance, reason (required unless OK) and data.
  • Every displayable number is a Quantity. value: null means not available — never 0.
  • This page is generated from web/lib/api/openapi.json; regenerate it with pnpm gen:api.

Evidence

GET/api/v1/evidence

Index of experiment records in the RecordStore registry, newest first (may be empty). Each record passes the provenance gate: unverifiable or fixture records are served as SYNTHETIC.

GET/api/v1/evidence/highlights

Headline numbers (SDP bracket, reproduced QBER, matched-topology latency) with source files and evidence.

GET/api/v1/evidence/labels

Display labels for every EvidenceKind, CertificateStatus and API status.

Errors

Every 4xx and 5xx response, including request validation, has the same body. Validation errors are 422 validation_error with pydantic's error list in detail; unknown routes and research ids are 404 not_found.
