Frozen contracts C0–C7

Lanes communicate only through frozen Pydantic v2 contracts in qmint/core/contracts.py (schema 1.0.0). JSON Schemas live in schemas/v1/, and their hashes are enforced by tests/contracts. Changes go to schemas/v2/ through a lead-approved migration.

Security games

A bound is valid only for its own game. QMint never moves a theorem across games: W1 ≠ W1_CV ≠ W2 ≠ S1 ≠ S2 ≠ D1 ≠ A1. The registry with theorem anchors is at GET /api/v1/games.

From lane to screen

A number reaches the screen through four steps, and keeps its label at each one:

  • A lane computes it and wraps it in a contract (for example an AttackResult with MONTE_CARLO evidence and a Clopper–Pearson interval).
  • The API turns it into a Quantity: value, unit, evidence kind, method, source and optional interval. A null value means “not available”, never 0.
  • The response envelope adds status (OK, DEMO_ADAPTER, NOT_AVAILABLE), reason and provenance (git sha, time, seed, software versions).
  • The web app renders the value next to its EvidenceLabel, generated from the same Python table.

Web application

The site is a Next.js App Router application in web/. The marketing route group serves /; the platform group wraps /app, /lab/*, /benchmarks, /certificates, /research and /docs in one shell (sidebar, breadcrumbs, ⌘K palette). Design tokens are in app/globals.css; primitives in components/ui; the typed client in lib/api.
