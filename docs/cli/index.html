CLI

The `qmint` command, its subcommands, exit codes and module entrypoints.

Usage

qmint is installed by uv pip install -e . ([project.scripts] in pyproject.toml); python -m qmint.cli is equivalent. doctor and sources are built in. Every other command is dispatched lazily to its lane's entrypoint module; nothing is fabricated when a lane is missing.

Built-in commands

CommandEffect
qmint doctor [--json] [--report PATH]Environment and dependency report; exit 0 when status is OK.
qmint sources list [--type paper|dataset|all]One JSON object per lane A source (PRIOR_ART_MATRIX.csv, DATASOURCE_REGISTER.yaml).

Lane commands

Each command forwards its arguments, including --help, to qmint.<lane>.entrypoints.cli_main. On this checkout no lane ships that module yet, so each prints NOT_AVAILABLE: lane X module … not merged and exits 3; use the module entrypoints below instead.

CommandLanePurpose
dataEfetch/validate public photonic datasets
proofsDverify published bounds / SDP primal-dual
simulateBprotocol simulations (wiesner, smoney, ...)
attacksCattack suites
baselinesHclassical baseline protocols
compilerIcertificate compiler optimize/verify
benchmarkNfrozen benchmark plan
figuresNregenerate figures from records
paperNbuild paper from evidence
qollabJoptional Qollab export

Exit codes

CodeMeaning
0ok
1failure (including doctor status other than OK)
2usage error
3NOT_AVAILABLE — the lane module is not merged
4BROKEN — the lane module exists but failed to import

Module entrypoints

Merged lanes expose these runnable modules today. All are deterministic for a given seed and offline unless stated.

ModuleLaneWrites
python -m qmint.proofs.reproduce --out DIRDreproduction_v1.json + example certificates
python -m qmint.attacks.report --out FILE [--trials N] [--seed S] [--clarabel-n2]Cattack + SDP evidence JSON
python -m qmint.classical.run_baselines --out DIR [--pqc-reps N]H23 BenchmarkRecords, PQC timings, comparability matrix
python -m qmint.photonics.schiansky2023 --out DIREQBER reproduction + calibration (needs the Zenodo archive in the data cache)
python scripts/run_core.py --offline --seed 42Lstage table, status JSON, verified manifest
python scripts/verify_manifest.py PATH…Lre-hashes manifests; exit 1 on mismatch
python -m qmint.api.export [--out DIR]Kopenapi.json + evidence-labels.json for the web client
