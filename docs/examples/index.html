Example experiments

Commands that were run and checked on this checkout, with what they write.

Check the environment

doctor prints dependency status, lane entrypoints (PRESENT or NOT_AVAILABLE) and ends with status: OK. sources list prints one JSON object per row of research/PRIOR_ART_MATRIX.csv (24 papers).

Reproduce published bounds

Recomputes every numerical example quoted by the registered sources and compares it with the paper (under a second, about one second). Each line reads [ok] name: paper=… qmint=…. Examples:

CheckPaperQMint
W1 min length for ε ≤ 1e-97373
W1_CV min length for ε ≤ 1e-9273273
S1 min length for ε ≤ 1e-9131131
P_noqub at μ = 0.09 (Kent 2022)0.00380.003815
W1 n=2 SDP, certified upper bound vs exact dual0.5625000000072769/16

It writes reproduction_v1.json and example certificates checked by lane D's independent checker. Those are worked examples of the certificate format for the stated hypothetical parameters, not claims about a deployed system.

Attack suite and SDP certificates

Runs the lane C attack suite (about 20 s at 2 000 trials): heuristic counterfeiters as Monte Carlo lower bounds, the n = 1 and n = 2 W1 SDPs (NUMERICAL_SDP), and exact rational dual certificates (CERTIFIED_NUMERIC, for example 3/4 ≤ OPT₁ ≤ 0.750000000003638). Add --clarabel-n2 for the Clarabel cross-check at n = 2, which needs about 6.5 GB of memory.

Classical baselines

Runs the classical comparators H0–H6 as deterministic state machines and writes 23 C6 BenchmarkRecords (MODELLED_LATENCY), ML-DSA timings and comparability_matrix.csv, which states where quantum and classical rows are not comparable.

Offline core run

Network is denied for the whole run. Stages whose lane has no entrypoints module yet are reported as SKIPPED with the reason; on this checkout that is every lane except L, so the run ends with PASS=2 FAIL=0 SKIPPED=9 and a verified manifest. Use --require-all to turn skips into failures.

Why most stages skip

Lanes are merged as libraries and module CLIs (above); the uniform qmint.<lane>.entrypoints wrappers are being added by the integration lane. Until then qmint simulate, qmint attacks and the other lane commands print NOT_AVAILABLE and exit 3.

Call the API

The attack call returns the MVW bound (3/4)⁴ = 0.31640625 as PUBLISHED_THEOREM and the exact measure-and-resend both-pass value (5/8)⁴ = 0.152587890625, each as a labelled Quantity. Its status and reason say which lane computed it.
