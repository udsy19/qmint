# P-C1: classical double-spend systems game (game C1)

**Status: UNSUPPORTED (pending lanes H/G).** This is a systems game, not a cryptographic theorem. The obligation is constructive: (i) a concrete event trace in which a copied classical bearer token is accepted at two sites without synchronisation (H0), and (ii) a trace showing that an online coordinator or quorum (H1/H2) prevents it while paying a modelled communication latency.

The proof engine returns no epsilon for any C1 request. It does not claim that classical cryptography is forgeable; signatures stop forgery, not copying.
