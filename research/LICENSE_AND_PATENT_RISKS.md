## Rules derived for QMint

1. QMint stays a **non-commercial research simulator**. It doesn't issue, redeem or transfer value, and it doesn't market "deployable" token configurations.
2. No third-party code is copied without recording an exact commit/DOI and a compatible licence in `licenses/REFERENCE_AUDIT.md`. AGPL/GPL code is never imported.
3. Datasets are downloaded at runtime with hash checks and attributed. Lane A doesn't commit raw third-party archives.
4. All theorem transcriptions cite the source and anchor (THEOREM_REGISTRY_SEED.yaml).
