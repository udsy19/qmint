Schiansky et al. 2023 SI Note 3: N=1 SDP (Eqs. 14-15), analytic fit of the secure-region boundary (Eqs. 16-18), finite-N Chernoff bounds for honest (Eqs. 19-21) and dishonest (Eqs. 22-23) success; main text Fig. 4b.

  • –Source emits states diagonal in photon number (SPDC; sigma_k of SI Note 3A with p0, p1, pm); multiphoton probability pm known.
  • –Attack model: general CPTP map on the token producing two classical cryptograms; TTP checks declared error e and loss l.
  • –N -> infinity: exponential de Finetti argument stated informally (SI Note 3B), i.e. collective attacks assumed asymptotically i.i.d.
  • –Finite N: Chernoff-Hoeffding (SI Eqs. 7-8) applied to the mishap count M(e,l) = (4+2 sqrt 2) e + l.

Caveatscaveats
  • –Secure-region boundary Eq. (16) is described by the authors as an analytic expression that FITS the numerical SDP optimum, not a proven closed form.
  • –The N->infinity step is an informal appeal to exponential de Finetti without finite-N correction terms.
  • –Chernoff bound (stated for sums of Bernoulli variables) is applied to the weighted mishap combination M(e,l).
  • –p_d excludes the MAC tag-forgery probability p_t = 1/sqrt|C|; the paper chooses p_d ~ p_t but states no composed epsilon. QMint does not compose them.
  • –Main text vs SI disagree: multiphoton probability 6.76 +- 0.12 % (main; reproduces main-text e_d = 3.79 %) vs p_m = 6.02 +- 0.28 % (SI Table 2; reproduces e_d = 3.82 % and allowed mishaps 0.4849); sub-token length N = 4.2e6 (Fig. 4b) vs 4,482,440 (SI Table 2). The published p_d = 5.911e-45 reproduces ONLY with N = 4.2e6 and p_m = 6.02 % (N = 4,482,440 gives 6.3e-48; p_m = 6.76 % gives 8.7e-45). Cross-checked with lane A (research/THEOREM_REGISTRY_SEED.yaml T-SCH23-FINITE).
  • –OPEN QUESTION (QMint assessment, not a claim of error): SI Eqs. (7)-(8) are multiplicative Chernoff bounds for sums of independent variables in {0,1}. The mishap variable per state takes values in {0, 1, 4+2 sqrt 2} (weight > 1 on errors), outside that hypothesis. Rescaling to [0,1] (divide by w = 4+2 sqrt 2) gives the textbook-valid exponent reduced by w: p_d <= exp(-(delta_d^2/2)(1/2)(1-p_m/2) N / w) = 3.3e-7 at the published tuple instead of 5.9e-45. The authors may have a different justification; until resolved D1 stays uncertifiable. Same issue for the honest bound (Eq. 19).
  • –Therefore results carry evidence kind PUBLISHED_AGGREGATE and status NUMERICALLY_SUPPORTED; the independent checker never marks a D1 certificate CERTIFIED.
