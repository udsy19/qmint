Statement summary

If max_{j,k} 2 P_MC(chi^k_j) < 1, N gamma_det <= n <= N, and 0 < P_noqub,theta < nu_unf < gamma_det (1 - gamma_err/(1 - P_bound)), with max 2 P_MC <= P_bound < 1, then eps_unf = sum_{l=0}^{floor(N(1-nu_unf))} C(N,l)(1-P_noqub,theta)^l P_noqub,theta^{N-l} + sum_{l=0}^{floor(n gamma_err)} C(n - floor(N nu_unf), l)(1-P_bound)^l P_bound^{n - floor(N nu_unf) - l}.
