Statement verbatim

Theorem 1. The optimal simple counterfeiting attack against Wiesner's quantum money scheme has success probability exactly (3/4)^n, where n is the number of qubits in each bank note.

Variablesvariables
n: number of qubits per bank note (positive integer)
Game definitiongame_definition

Bank picks key k uniformly at random, i.e. each of n qubits is |0>,|1>,|+>,|-> with probability 1/4 independently (n-fold parallel repetition of the single-qubit ensemble, Sec. 3.4). The counterfeiter receives ONE note (register X) and applies any CPTP map Phi: L(X) -> L(Y (x) Z). Success = both Y and Z independently pass the bank's projective test {Pi=|psi_k><psi_k|, 1-Pi} (eq. 2, p.7: sum_k p_k <psi_k (x) psi_k| Phi(|psi_k><psi_k|) |psi_k (x) psi_k>).

Sdp n1sdp_n1
primal: maximize <Q,X> s.t. Tr_{Y(x)Z}(X) = 1_X, X >= 0 on Y(x)Z(x)X (p.7)
dual: minimize Tr(Y) s.t. 1_{Y(x)Z} (x) Y >= Q, Y Hermitian on X (p.7)
Q: 'Q = sum_k p_k |psi_k psi_k conj(psi_k)><psi_k psi_k conj(psi_k)| ; for Wiesner n=1: Q = (1/4)(|000><000|
  + |111><111| + |+++><+++| + |---><---|) (p.8)'
subsystem_order: 'Choi operator J(Phi) in L(Y (x) Z (x) X), output registers first, input last (Sec. 2.2:
  J(Phi) = sum_ij Phi(|i><j|) (x) |i><j|)'
optimal_primal: Phi(rho) = A0 rho A0^* + A1 rho A1^*, A0 = (1/sqrt12)[[3,0],[0,1],[0,1],[1,0]], A1 = (1/sqrt12)[[0,1],[1,0],[1,0],[0,3]]
  (4x2 matrices, output basis |00>,|01>,|10>,|11>) (p.8)
optimal_dual: Y = (3/8) 1_X ; ||Q|| = 3/8 (p.8)
optimum: 3/4
