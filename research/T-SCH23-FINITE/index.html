Statement summary

Honest success p_h >= 1 - exp(-(delta_h^2/3) M(e_h,l_h) N) (20), subject to M(e_h,l_h)(1+delta_h) < (1/2)(1-p_m/2) (21). Dishonest success p_d = P[M(e_d,l_d) <= (1-delta_d)(1/2)(1-p_m/2)] <= exp(-(delta_d^2/2)(1/2)(1-p_m/2) N) (22), with (1/2)(1-p_m/2)(1-delta_d) >= M(e_h,l_h)(1+delta_h) (23). N = number of quantum states used to verify ONE bit of the cryptogram. Total token length lambda = N log2|m| = N log2 sqrt|C|.

RECOMPUTED_BY_LANE_A: exp(-(0.01^2/2)*0.5*(1-0.0602/2)*N) gives 5.91e-45 only with N = 4.2e6 (exponent 101.84). With the SI Table 2 N = 4,482,440 it gives 6.3e-48. So the reported p_d uses N = 4.2e6 and p_m = 6.02%.

Caveatscaveats
  • –Chernoff-Hoeffding (SI eqs 7-8) is for sums of independent {0,1} variables. M = (4+2 sqrt2) e + l is a weighted combination with weight > 1. Lane D must check whether the bound is applied within its hypotheses (open question, NOT a claim of error).
  • –Independence across the N states is assumed in the Chernoff step.
  • –MAC forgery p_t = 1/sqrt|C| (main text; SI Note 4) is a separate term. The overall cheating probability composition is not stated as a single theorem.
